Architecture & Data

数据主权在你手里

部署在你自己的基础设施上

系统由 Electron 桌面端与 Flask API 组成，业务数据保存在部署者自己的 PostgreSQL、Redis 与文件存储中——不上传第三方 SaaS，客户资料与门禁证据原件始终留在本地工作目录。

桌面端（Windows / macOS）通过受限 IPC 调用后端；后台任务为自研 Redis 队列；集成桥对本地 openfde / fdeops 工作目录做只读投影。

  • argon2 口令哈希，口令不明文落库
  • 双令牌机制：15 分钟 access + 30 天轮换 refresh，改密即失效
  • 登录防爆破：连续失败锁定，Redis 计数
  • 容器非 root 运行，密钥后端加密保存且不经 API 回显
  • 客户资料永不进代码仓库：仓库与数据库只存代号
