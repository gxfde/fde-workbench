## 承诺与上线检查

- **无任何密钥打包进客户端**：桌面只烘 `fdeApiUrl`（非密钥）；刷新令牌运行期存 OS 安全存储。
- **密钥不经 API 回显**（README 数据与安全节）；错误响应经 redact（`desktop/src/main/auth-ipc.ts:317`）。
- 上线前：确认 `server/.env` 权限；`FDE_JWT_SECRET` ≥32 随机字符；桥令牌非默认；gitleaks CI 绿。
- 泄露应急：先轮换对应供应商密钥/DB 口令，再评估 FDE_JWT_SECRET 连带（模型凭据密文）。
