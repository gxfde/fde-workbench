## 3. 真实执行面接线（IT-01 落地）

### 3.1 沙箱项目（`simulation/sandbox.py`）

| 项 | 落点 |
|---|---|
| 项目 | `SIM-V32-LAB` /「FDE 交付模拟训练场（仿真沙箱）」／代号 `SIM·训练场·平台`（三段两枚「·」照旧） |
| 权限 | 仅 **admin** 可建（平台资产，不是任何人的项目） |
| 幂等 | 按 `project_code` 查复用；同代号出现第二个即冲突（409） |

**投影纪律（两条，不可越界）**：
1. **只投已披露事实**——未披露的隐藏事实**不进** Agent 上下文（否则等于把答案喂给被测方）；
2. **骨架是任务说明不是答案**——期望结果 / 验收标准 / Rubric **绝不**进沙箱骨架
   （骨架只写「你是 FDE 顾问，请基于已确认业务问题产出需求/方案/任务/验收」）。

投影落点与既有上下文面**同构**：已披露事实 → `ProjectGuidanceAnalysis`（status=confirmed，
`key_business_problems_json` 的 `confirmed=true` 条目）＋ 任务骨架 → `ProjectSolution`。

**重投影用「取代」不用「删除」**：旧分析置 `superseded`（状态机内既有态），方案骨架
**就地更新**——产物行可能挂 solution 外键，删除会撞 FK；上下文渲染取最新 confirmed ⇒
上一次的已披露事实不会泄漏给下一次。

### 3.2 真实适配器（`simulation/adapters/real.py`）

| 相位 | V3.1 能力档 | 语义 |
|---|---|---|
| analysis | `agent.module.presales` | 需求澄清 / 问题识别 |
| design | `agent.module.solution` | 方案骨架 |
| implementation | `agent.module.deployment` | 实施与产出 |
| validation | `agent.module.acceptance` | 独立验收（**结论仅参考**） |

**为什么访谈仍是确定性探针**：真实执行面是「**一次性任务型**」智能体（spawn CLI +
任务书 + 工作区），**没有多轮对话接口**；且训练场要求同 seed 复现同一结果。
⇒ **多轮访谈用确定性探针，一次性产物生成用真实执行面**——这是能力形态的客观差异。

**诚实标注**：`integration_status ∈ {exercised, wired_not_exercised}`——
只有真实 run 走到终态**且**产出产物才算 `exercised`；否则明确标「接线在、没真跑」。

**失败即失败**：真实面不可用（智能体未启用 / 无 zcode CLI / run 失败）⇒ 运行落
`failed` + `error_json.code=adapter_unavailable`，**不静默退回 mock**（执行器层
`AdapterUnavailable` 捕获）。

### 3.3 真实产物的判定口径

真实产物是**自由文本**（agent 写进工作区的文件），拿不到 mock 那样的结构化字段
（requirements / tasks / acceptance_criteria）。处置：

- 产物契约带 `structured=false` ⇒ 规则层里**依赖结构化字段的判据按「无证据」处理
  （不入账，不是判 0 分）**；
- **语义判断交给模型层**（§4）——这正是模型层必须接线的现实理由；
- 仿真域只存**摘录 + sha256 + 指针**（≤4000 字符），原件留在工作区（不搬进库）。

## 5. Rubric 覆盖度校准（G8 §2.1 缺口闭合）

**改法**：覆盖判定从「精确子串」改为**确定性字面重叠**（`simulation/textmatch.py`）：
中文按字二元组、英文按词，Rubric 侧成分被覆盖的比例 ≥ **0.25** 即命中。

**阈值是实测标定的**（不是拍脑袋）：对 6 案例的 22 条 `must_identify` 与各自 5 条
隐藏事实逐条求重叠率——命中项 0.25–0.69、非命中项 0.00–0.14 ⇒ 取 0.25（低于它会
开始把交付物类条目误判为命中）。**只适用于事实类**；交付物类（`must_produce`）
走**另一套判据**：在**交付正文**上判（§3.3）。

**复测效果**（验收脚本重跑，18 次模拟）：

| | G8 初测（精确子串） | G9 复测（字面重叠） |
|---|---|---|
| 不同分数个数 | **1**（全同分） | **7**（0.735–0.925） |
| 平均分 | 0.7350 | **0.8314** |
| verdict | 18 conditional | 15 pass / 3 conditional |
| 失败发现 | 36 | **16** |

⇒ 训练场现在**能分辨「问得深 ↔ 知道得多 ↔ 产出更全」**。

**仍存的口径限制（不掩盖）**：字面重叠不是语义理解——同义改写仍会漏判（22 条里
仍有 6 条未命中）；语义层面由模型层承担。
