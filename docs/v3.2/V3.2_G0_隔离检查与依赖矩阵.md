## 9. 数据隔离与安全硬约束（G0 级结论，G1 细化）

1. **不挂 `projects.project_id`**：模拟运行自持命名空间，杜绝混入真实项目视图与成本账本。
2. **禁止真实副作用**：模拟环境内不得出现真实邮件、真实 CRM 写入、真实生产库写操作、真实外部 API 调用。工具层须**白名单式**只暴露虚拟工具。
3. **模拟数据显式标记**：所有模拟实体带 `simulation` 标记与前缀（如 `SIM-`），检索面可一键排除。
4. **Trace 全量留痕**：每次工具调用、每次状态变化、每次产物产出都落 Trace，可复现。
5. **降权执行**：模拟环境权限**低于**生产档；模拟 Agent 即便提出危险操作，也只在虚拟环境验证其行为。
6. **参考答案隔离**：场景「标准答案 / 参考解」存放于评分侧专表，**绝不进入被测 Agent 的可见上下文**（防过拟合，这是 4.2 节案例设计的前提）。
7. **数据集三分**：训练集 / 回归集 / 盲测集物理隔离（独立标签 + 独立装载路径），盲测集标准答案不对被测方暴露。
