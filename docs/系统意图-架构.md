# 系统意图：架构与信任边界

> 本文是系统意图文档的**根文档**（goal-r3 G2 产出，2026-10-30；**快照更新 2026-11-07 架构评估修复轮**——行号/计数以当次 CI 实测与 fork/main 为准，差异逐处见正文注记）。部署、命令与迁移的**唯一权威是仓库根 README.md**；本文只描述「系统本应是什么样」，供评审与意图比对（见 `系统意图-关键流程/权限矩阵/变量与密钥/测试覆盖地图/定时任务/自动化面`）。事实全部引用代码位置。

## 系统是什么

FDE（前端部署工程师）交付工作台：为单团队交付 somwyn 类项目提供 项目→门禁→报价收款→交付 的全流程留痕。

- **桌面端** `desktop/`：Electron + React（electron-vite），主进程代理一切 HTTP/IPC（渲染层不直接持密钥）。
- **服务端** `server/`：Flask + SQLAlchemy + PostgreSQL + Redis，四容器编排（redis / api / worker / scheduler，`compose.yaml`）。
- **真相层**：本地 openfde / fdeops 工作目录（`D:\test\FDE\…`，永不入仓库）；工作台只存代号与指针投影。

## 信任边界（跨过即需鉴权/校验）

| 边界 | 信任的一侧 | 防线 |
|---|---|---|
| 渲染进程 → 主进程 IPC | 只信主窗口帧 | `isTrustedSender`（sender===mainWindow && URL 白名单） |
| 桌面 → API | 无（HTTPS + Bearer） | JWT + `require_auth`/`require_role`/`project_access` |
| 宿主计划任务 → API | `FDE_BRIDGE_TOKEN` 静态令牌 | `bridge/runner.py:40-48`（未配置=桥整体 503 关闭） |
| API → AI 供应商（DeepSeek/Kimi/DSH） | 不信任出网响应 | 输出过 `validate_guidance_output` 合同校验；直连模式只暴露只读工具白名单 |
| 文件上传 → 对象存储 | 不信任文件内容 | ClamAV 扫描（`scan_status`），仅 clean/not_required 可被 AI 读 |
| 真相层 → 工作台 | 只读投影 | `bridge-poll.mjs` 只调 openfde 只读 CLI + 读文件，绝不写真相层 |

## 已知风险与假设（均有代码证据）

1. **JWT 密钥是本地加密根**：`FDE_JWT_SECRET` 泄露=可伪造任意角色令牌（HS256 对称签名）。换机迁移必须原样携带（README 迁移清单）。
2. **桥令牌是长期静态 Bearer**：无轮换机制，泄露即他人可推送假快照（写入受限桥表，非任意写）。
3. **模型凭据 Fernet 密钥缺省派生自 JWT secret**（`control/model_preferences.py:42-47`）——轮换 JWT secret 不会自动轮换已入库密文，需人工评估。派生语义已由测试钉住（2026-11-07 架构评估修复轮：`server/tests/test_model_credential_key_derivation.py` 三例——缺省派生可解/轮换即 credential_unavailable 且密文本体不变/独立密钥隔离）。
4. **登录限流依赖 Redis**：Redis 挂时默认 fail-open，仅 `FDE_LOGIN_RATE_FAIL_CLOSED=1` 才拒绝（`auth/limits.py`）。
5. **AI 直连降级模式**（无 DSH runtime 时）信任供应商响应经本地工具循环放大：工具面已收窄为只读白名单 13 个（`control/ai_tool_loop.py:42-56`，+gates_read；2026-11-07 现测），写类工具不提供。
6. **客户真实资料只进文件系统**：仓库/数据库仅代号；门禁证据只存 `source_uri` 指针 + sha256（`gate_service.py`，红线）。
