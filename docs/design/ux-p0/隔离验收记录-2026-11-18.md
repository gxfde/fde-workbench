## 发布条件

生产审批覆盖仓外调用、在用安装、兼容窗口期限、监控方式、应急暂停负责人、客户端回退以及全实例严格切换。仓库 `compose.yaml` 暴露回环 API 端口，桌面和脚本可以直连——这也是暂停手段选「服务端单点开关」而非反向代理的原因：一处开关即可覆盖全部入口。

回退步骤（需授权后由发布负责人执行）：① 置 `FDE_UX_WRITE_PAUSED=1` 并重启 api；② 用桌面、脚本、网页各发一次三条写入，确认均 503 `write_preconditions_paused` 且 `operation_events` 无新增成功事件；③ 再执行版本回退；④ 恢复后置回 0，重跑同一组探针确认可写，然后让用户重读确认再办理。

暂停态下三写已实测被拒且零业务事件、封包保持 `sealed`、门禁版本不变（见上）。仍未完成：实际安装与仓外调用方盘点、生产审批。P0 的实现与隔离验收已完成并合并，严格切换与活体部署待单独授权。
