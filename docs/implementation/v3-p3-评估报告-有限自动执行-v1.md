### 2.2 运行数据要求与取数口径（口径先行，首批真实 run 后回填）

数据闸现状（#125 §0 实测，2026-11-05）：`automation_approvals=0` 行、`workflow_runs=0`、`agent_runs=0`——**运行证据尚不存在，本轮只落口径**。以下四口径全部基于实测列名（`control/models.py:177-201`、`workbench/models.py:884-905`），活库可直跑：

| 口径 | 定义 | SQL 骨架 |
|---|---|---|
| A 审批时效 | requested→reviewed 时延 p50/p90，按 risk_level×capability 分组；健康线由实施轮拍板 | `SELECT risk_level, capability, percentile_cont(0.5) WITHIN GROUP (ORDER BY EXTRACT(EPOCH FROM (reviewed_at - created_at))) AS p50_s, percentile_cont(0.9) … AS p90_s FROM automation_approvals WHERE reviewed_at IS NOT NULL GROUP BY 1,2;` |
| B 人工否决率（误判率代理） | AI 发起被人工拒绝的占比：`rejected / (approved + rejected)`，按 capability×tool_name×risk_level 分组；`expired`（超时未批）单列为流程健康度，**不计入误判** | `SELECT capability, tool_name, risk_level, COUNT(*) FILTER (WHERE status='approved') AS ok, COUNT(*) FILTER (WHERE status='rejected') AS rej, COUNT(*) FILTER (WHERE status='expired') AS exp FROM automation_approvals WHERE status IN ('approved','rejected','expired') GROUP BY 1,2,3;`（status 词表= models.py:20 CHECK） |
| C 执行落空检测 | approved 但超时窗内 `executed_at IS NULL` → 预警（审批与执行腿脱节） | `SELECT id, capability, reviewed_at FROM automation_approvals WHERE status='approved' AND executed_at IS NULL AND reviewed_at < now() - interval '1 hour';` |
| D 确认失败锁事件 | 密码确认失败计数（`fde:ai:confirmation-failures:<user_id>`，api_actions.py:238）触锁事件在 operation_events 的投影（`changes.confirmation_required` 面，:198）——确认闸被滥用的信号 | 按 `event_type` + `changes->>'confirmation_required'` 聚合 operation_events |

### 3.2 本轮补：三条断言式回溯 SQL

| # | 断言 | SQL | 期望 |
|---|---|---|---|
| 1 | 审批链双侧人签 | `SELECT a.id FROM automation_approvals a WHERE a.status IN ('approved','executed') AND (a.reviewed_by_user_id IS NULL OR a.reviewed_at IS NULL OR a.requested_by_user_id IS NULL);` | 0 行 |
| 2 | 发起链实名 | `SELECT r.id FROM workflow_runs r LEFT JOIN users u ON u.id = r.initiated_by_user_id WHERE u.id IS NULL OR NOT u.is_active;` | 0 行（executor 对发起人不可用已诚实失败，executor.py:946-948） |
| 3 | 全事件落人 | `SELECT e.id FROM operation_events e WHERE e.actor_user_id IS NULL;` | 0 行（FK NOT NULL 结构性保证；活库 44 事件 3 actor 全实名，#125 §0） |
