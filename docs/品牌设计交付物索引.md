## 五、阅读顺序建议

1. 先读《品牌全案策划书》§一–§二（为什么做、定位与待确认项）。
2. 再读《品牌手册》§02/§03/§08（怎么用、正误对照）。
3. 做具体物料时按清单编号查对应 `specs/` 分组。
4. 改色值/话术前先读 `BRAND-CHANGELOG.md` 与 F2 的生成物规则。

## 六、重要提示

- **不要复制色值**：其他文档只写「见 `BRAND-COLOR-SPEC.md §X`」。
- **不要改写一段话介绍**：以 `BRAND-LOGO-GUIDE.md §〇` 为准（2026-11-05 已修正为 13 阶段交付 SOP + G1–G9 门禁）。
- **「九步交付法」全仓禁用**；门禁名称以 `server/seeds/gates.json` 为准。
- **B3 数据可视化色板保留「留待图表需求出现时补」，未发布任何色值**。
- 多项发布/资质/联系方式仍标「待确认」，见 `BRAND-COMPLETION-INDEX.md §八`，不得臆造。
