# 系统意图：权限矩阵

> 角色 × 资源 × 操作的静态基线（goal-r3 G2，2026-10-30；**快照更新 2026-11-07 架构评估修复轮**——锚点现测校正）。运行时顺序见 `系统意图-关键流程.md`。实现：`server/src/fde_api/auth/permissions.py`、`auth/decorators.py`、`projects/permissions.py`、`control/access.py`。

## 角色模型（三套，勿混）

| 体系 | 值 | 定义处 |
|---|---|---|
| 系统角色（4 级全序） | viewer < fde_engineer < project_lead < admin | `auth/permissions.py:1-6`（ROLE_RANK）、`auth/models.py:17-20` |
| 项目成员角色（2 种） | member / viewer | `workbench/models.py:322-323` |
| AI 访问级别（5 级） | disabled < assistant_read < project_operator < project_manager < system_operator | `control/access.py:14-26` |

**判定原语**：`require_auth`（JWT + 强制改密锁 3 路由例外，`decorators.py:18-49`）；`require_role`（精确集合）；`require_minimum_role`（等级）；`project_access`（admin 全真；leader 且系统角色 ≥project_lead 得 manage；成员 viewer 只读；非成员全拒——`projects/permissions.py:20-41`）；`authorize_ai_capability`（能力表 + 级别交集，`control/access.py:27-97`）。scope 一律 DB 实时判（令牌只带 role，权限回收即时生效）。

## Deny 场景清单（测试锚点）

| 场景 | 返回 |
|---|---|
| JWT 无效/过期/auth_version 失配 | 401 `access_token_invalid`（auth_version 判定 `decorators.py:124`） |
| 角色不符 / 强制改密期 / 账号停用 / project_access 拒 / AI 级别 disabled | 403（`decorators.py:39-131`、`chat.py:76`） |
| 桥令牌错误 / 未配置 | 401 / 503（`runner.py:42-48`） |
| 文件跨项目读 | 404 掩护（`files/service.py:909`） |
| 在任最后 leader 降级/停用 | 409（users/service.py 语义不变，行号现测前重锚） |

**行级安全**：无数据库层 RLS；全部依赖上述代码级检查（`project_access` 是唯一项目隔离原语）。
