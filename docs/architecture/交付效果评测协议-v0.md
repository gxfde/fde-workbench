## 1. 算分口径（uplift）

`uplift = (kpi − kpi_baseline) / (kpi_oracle − kpi_baseline)`

- 0 = 未改系统（do_nothing 基线）；1 = 参考解（oracle）；>1 允许（超越参考解）。
- **PASS 线 = 0.8**；分数**截断不四舍五入**（防 0.7999 侥幸过线）。
- **incidents 非空 ⇒ uplift ≤ 0**——发生事故（回归/越权/数据损坏）一票封顶，无论业务指标多好。
- `uplift_bounded = max(−1, uplift)`——恶意倒退最多记 −1，防分数武器化。
- `span = kpi_oracle − kpi_baseline = 0` ⇒ 返回 0，**不除零**。
- **无 oracle（kpi_oracle 缺失或不可回放）⇒ 不出分**，result 返回 `insufficient_data`（我方 `metrics/service.py` 同名纪律先例）。

## 3. 门禁判据升格：三锚点 + 四类反例（B#22）

现状缺口：我方门禁/检查器只做「一正一试」，无法回答「这个分数测的确实是它声称测的东西」。升格判据（全部为**协议文本**，pytest 断言模板先成文不接线，实施落点=B#11，不另立判据）：

**三锚点**（分数必须落在正确位置）：

| 锚点 | 参考阈值 |
|---|---|
| `do_nothing`（什么都不做） | ≈ 0 |
| `literal`（照字面最小改动） | ≤ 0.2 |
| `oracle`（参考解重放） | ≥ 0.95 |

**四类反例**（每类必须被抓住）：

| 反例 | 参考阈值 |
|---|---|
| `shortcut`（抄近路绕过要求） | ≤ 0.8 |
| `bypass`（绕过门禁/幂等直接改终态） | ≤ 0.05 |
| `memorised`（背答案——跨变体失效） | 跨变体均值跌穿 0.5 |
| `alternate`（等效替代解） | **只报告不封顶**（等效解不该被罚） |

**附加规则**：跨变体均值线（0.5 不过 / 0.8 过）+ 变体角度 ≥3 + `judge` 输出必须含命中对象数——**0 个不算通过**（检查器空转 ≠ 守住）。

## 4. 验证/验收合同契约五点（B#29，并入本协议）

对齐我方 G8 `conditional_pass` / G9 有条件接受语义，五点缺一不构成有效验收合同：

1. **指标溯源**：每个指标必须引用此前阶段真实项目文档**且给出文档内编号**——不许凭空定义 KPI。
2. **摘要覆盖域**：确认文件 SHA-256 摘要**只覆盖候选/环境/数据/指标定义**，**不覆盖**执行结果/证据/问题状态/FDE 决定 ⇒ 改定义使旧确认失效、正常写回结果**不**失效（我方 `api_actions.arguments_sha256` 同构思想）。
3. **人工接受不粉饰**：`waiverReason` / `manualAcceptance.reason+acceptedAt` 保留真实 NOT_RUN/FAIL、证据缺口、数值与说明——有条件通过必须写明「条件是什么、缺什么」（对齐 G8 书面三态）。
4. **部分损坏整体无效**：单指标格式错误保留其余有效字段便于诊断，但整份合同仍无效——不生成摘要、不推进阶段。
5. **拒绝过期摘要**：精确操作一律拒绝过期摘要（15min 窗语义，同 `api_actions` 确认闸）。
