## 0. 一句话裁决

**三锚四反例的宿主＝B#23 离线评测夹具的「评测器元验证层」**——它们验证的不是交付物，而是**给交付物打分的检查器本身**（do_nothing≈0 = 检查器不给空转打分；oracle≥0.95 = 检查器认得出参考解）。门禁面的落点**已随 #131 冻结**（G9 `exit_condition` 公式含「三锚四反例全过」）；pytest 断言模板的落点＝四条件解封后 NEW `server/tests/test_eval_criteria_harness.py`。**本文不建任何检查器、不动任何判据文本。**

## 1. 被验证对象：我方机器判据面清单（诚实盘点）

| 判据面 | 现态 | 与三锚四反例的关系 |
|---|---|---|
| 门禁 G1–G9 清单项核验 | **人工**（提交指针+指纹 → 人核验拍板，`gate_service`） | 不是机器打分器；三锚四反例不适用于人 |
| G9 `exit_condition` | **种子冻结公式**（#131：`验收线达成 ≔ uplift_bounded ≥ 0.8 ∧ incidents = ∅ ∧ 三锚四反例全过`＋insufficient_data 边界；重生成覆盖由 `test_state_ownership_reconciliation` 钉 6 守护） | **判据已落门禁面**——本文 §2 只确认落点、不加字 |
| T-G2 `template_outdated` | 机器布尔（冻结哈希 vs 现行种子） | 单点布尔检查器；属「一正一试」现状，其元验证不在三锚四反例范围（无分数语义） |
| B#2 回执 scanner 四态 | 机器分类（`ManifestOutputScanner.receipt_state`）＋五用例（含干净对照=近锚思维已具雏形） | 未来若升级为打分器，须过本落点元验证 |
| uplift 算分器 | **未建**（B#23 夹具期产物；`insufficient_data` 是唯一合法输出直至解封） | **三锚四反例的主宿主**——算分器上线前必须先过元验证 |

结论：**当前仓内尚无「打分型检查器」**（全部为布尔/枚举判定或人工），因此三锚四反例**现在没有任何可验证对象**——它们是为 B#23 算分器预置的验收合同。这决定 §2 的落点形态。

## 2. 落点总图

```
交付效果评测协议 v0（冻结口径：算分 §1 / result §2 / 判据 §3 / 合同 §4）
        │
        ├─ 门禁面落点【已冻结 #131】
        │    gates.json G9.exit_condition 含「三锚四反例全过」
        │    （钉 6 守护重生成覆盖；存量 Gate 行不改=template_outdated 呈现漂移属设计）
        │
        ├─ 夹具面落点【B#23，四条件解封】
        │    评测器（uplift 算分 + 检查器）实现
        │    └─ 元验证层【=本文落点】NEW server/tests/test_eval_criteria_harness.py
        │         三锚：do_nothing≈0 / literal≤0.2 / oracle≥0.95
        │         四反例：shortcut≤0.8 / bypass≤0.05 / memorised 跨变体<0.5 / alternate 只报告
        │         附加规则：跨变体均值线 / 变体角度≥3 / judge 命中对象数>0
        │
        └─ 本文【B#11】＝上述落点的契约（谁持有/何时接线/断言形状），零补码
```

**元验证语义（我方定义）**：评测器开发完成后、其分数可用于任何「验收线达成」判定前，必须以三锚四反例夹具对**评测器自身**跑一遍——锚点不落位或反例漏抓 ⇒ 该评测器的输出不得作为 G9 判定输入（`insufficient_data` 唯一合法输出不变）。此即「检查器空转 ≠ 守住」的机器化。

## 3. 逐判据落点表

| 判据（协议 §3 冻结文本） | 宿主 | 输入 | 断言形状 | 前置闸 |
|---|---|---|---|---|
| `do_nothing` ≈ 0 | 元验证层（test_eval_criteria_harness） | 夹具空跑工作区 | 评测器对空跑输出 `score < ε`（ε 由我方数据校准，不照抄 0.05 字面） | B#23 解封 |
| `literal` ≤ 0.2 | 同上 | 字面最小改动夹具 | 分数上界断言 | 同上 |
| `oracle` ≥ 0.95 | 同上 | 参考解重放 | 分数下界断言；**参考解永不入库**（B#25 红线，夹具以受控注入） | 同上 |
| `shortcut` ≤ 0.8 | 同上 | 绕要求夹具 | 分数上界断言 | 同上 |
| `bypass` ≤ 0.05 | 同上 | 绕门禁/幂等直改终态夹具 | 分数上界断言；**绕过行为本身还须触发 P3 评估报告红线**（写类 external 永不降级） | 同上 |
| `memorised` 跨变体 < 0.5 | 同上 | 同题多变体（角度 ≥3） | 跨变体均值跌穿断言 | 同上 |
| `alternate` 只报告 | 同上 | 等效替代解夹具 | **不封顶**；断言评测器输出含 `alternate_reported` 类标记 | 同上 |
| 跨变体均值线 0.5/0.8 | 同上 | 多变体批量 | 阈值断言（校准后落常量） | 同上 |
| 变体角度 ≥ 3 | 元验证层自身 | 夹具清单 | 夹具完备性断言（角度数不足 ⇒ 元验证失败） | 解封后建夹具时即生效 |
| judge 命中对象数 > 0 | 同上 | 各反例 | 「0 个不算通过」断言（空转检查器直接判负） | 同上 |

**阈值纪律（协议 §3 已载）**：表中参考阈值全部须经**我方数据校准**后方可落常量；未校准前以 `insufficient_data` 语义挡在判定外。
