# 系统意图：自动化面（AI 与外部自动化）

> 内嵌 AI、任务自动化与外部桥接的触发/工具面/输出契约/开关（goal-r3 G2，2026-10-30；**快照更新 2026-11-07 架构评估修复轮**——工具计数/文件锚点/降级面现测校正，新增翻译器管道节）。核心原则：**App 拥有副作用，AI 只产出建议**；写路径一律过确认流或人工拍板。
