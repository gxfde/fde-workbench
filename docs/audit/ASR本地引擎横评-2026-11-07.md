# ASR 本地引擎横评报告（2026-11-07，goal-tb tb1 前置实测）

> 归属：立项文档《录音转写ASR通道立项-v1.md》§3.3.1 **P2（引擎与模型档位）/ P3（宿主运行形态）** 拍板项的实测数据；随 T-A9 实施轮 PR 归档（立项文档 §6 第 2 步要求）。
> 拍板背景：2026-11-07 蔡工「ASR 通道选型：按你建议实施」→ opt-L 本地 ASR 先行（§拍板闸 6⑩）。
> 红线对齐声明：**全程零外发**——测试音频由本机 SAPI（Microsoft Huihui，zh-CN）合成，引擎推理全部本地 CPU；音频、模型、原始输出只留本地工作目录 `D:\test\FDE\asr-bench-local\`，**永不进仓**；文本为自拟虚构内容（虚构企业「青禾智造」），零客户真实资料。

## 1. 方法

- **素材**：本地 TTS 合成两段 16kHz/16bit/mono WAV——`clip-zh.wav`（68.7s，生产排程场景虚构叙述，含数字、Excel 一处英文词）；`clip-mixed.wav`（20.2s，中英混说观察项：SAP B1 / SQL Server / Modbus TCP / REST API / Webhook / WMS）。
- **基准答案**：合成文本原文（TTS 朗读稿），保存于 `audio/clip-*.txt`。
- **引擎**：`faster-whisper` 1.x（CTranslate2 int8，CPU）× tiny/base/small；`whisper.cpp` b5454 预编译 x64（`whisper-cli.exe`）× 同三档 ggml 模型。FunASR（Paraformer）因 torch 依赖链过重（约 2GB）本轮**不实测**，如实注记不充当候选结论。
- **指标**：CER（字错率）＝归一化后编辑距离/参考长度——归一化含**繁→简转换**（OpenCC t2s；whisper 家族常输出繁体，不归一会虚高 3–28 个百分点）＋去空白与中英标点；耗时＝处理墙钟时间（faster-whisper 为纯转写段，whisper.cpp 含进程启动与模型加载）。
- **真机**：Windows 宿主裸跑（无 Docker、无 GPU），与 P3 宿主形态拍板一致。

## 2. 结果（2026-11-07 实测）

| 引擎 | 模型档 | clip-zh CER（68.7s 音频） | 处理耗时 | 实时倍率* | clip-mixed CER（中英混说） | 处理耗时 |
|---|---|---|---|---|---|---|
| faster-whisper | tiny | 0.1094 | 8.3s | 8.3× | 0.1505 | 2.1s |
| faster-whisper | **base** | **0.0859** | **17.3s** | **4.0×** | **0.0645** | 3.9s |
| faster-whisper | small | 0.0781 | 73.8s | 0.93× | 0.0323 | 16.7s |
| whisper.cpp | tiny | 0.1133 | 14.3s | 4.8× | 0.1505 | 5.3s |
| whisper.cpp | base | 0.0859 | 25.9s | 2.7× | 0.1183 | 9.3s |
| whisper.cpp | small | 0.0586 | 94.3s | 1.37× slower | 0.0430 | 30.2s |

\* 实时倍率＝音频时长/处理耗时；<1 表示慢于实时。

## 3. 结论（P2/P3 落定）

- **P2 ＝ faster-whisper，base 档（int8/CPU）为推荐默认档**：中文 CER 8.6%、中英混说 6.5%，且 1 小时访谈约 15 分钟出稿（4× 实时）；small 档中文仅再降 0.8 个百分点却掉到实时线附近（1h 访谈≈1h 等待），不合访谈场景性价比。tiny 档混说 0.15 不可接受。
- **P3 ＝ Windows 宿主裸跑确认**：两引擎在宿主 CPU 裸跑均零摩擦完成（无音频设备/模型挂载问题）；结合 T-Z1 登记实测（服务端 Linux 容器 subprocess 够不到宿主侧工具），ASR 引擎**不进平台依赖、不进容器**——转写以宿主侧产出文本经草稿 API 进入工作台（引擎字段仅记录来源标注）。
- **专有名词是共同弱点**：「青禾智造」两引擎一致听成「清合制造」——虚构专名即全错。这正是 T-A9 设计「草稿只落草稿区、人工整理＋客户确认后才晋升」的原因：**转写稿永远经人工校对，不直接消费**。
- **平台侧零依赖**：`server/` 无任何 pip 新增、无模型文件进仓、无引擎代码进仓；横评工具链（venv/脚本）全部留在本地工作目录，本报告只归档方法与数字。

## 4. 局限性（如实登记）

1. **合成音频 ≠ 真实访谈**：TTS 音频无房间噪声、无多人重叠、语速均匀——真实录音 CER 必然更高。本横评用于**引擎间相对比较与档位选型**，不作为准确率承诺；首批真实访谈（客户口头同意后）应抽样复测并回写本报告。
2. 单说话人、单话筒口径；说话人分离（diarization）不在本轮范围。
3. FunASR 未实测（torch 依赖约 2GB，与「宿主轻量裸跑」目标不匹配）；若 faster-whisper 真实复测不达标，FunASR 作为下一候选再实测。
4. whisper.cpp 耗时含进程启动（每次冷启）；长音频按比例外推时两者差距略收窄，不改变档位结论。
