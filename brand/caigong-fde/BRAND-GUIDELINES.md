## 00 · 如何使用本手册

- 做物料前先查**第 08 章正误对照**，再按载体查第 06/07 章应用示例，最后回到对应规范取精确参数。
- 本手册与《品牌全案策划书》分工：策划书回答「为什么」，本手册回答「怎么用」；清单只用于看进度。
- 需要改色值 → 只改 `BRAND-COLOR-SPEC.md` 与 `build_logo_svgs.py`，重跑生成器；**不得**直接改手册里的引用。
- 本手册所有「待确认」项见第 09 章与 `BRAND-COMPLETION-INDEX.md`。

## 02 · 主标系统

### 2.1 构造与几何

CG 环形标：C+G 对应「蔡工」；单笔连续成环 = 需求到验收的闭环；右上金色独立段为全场唯一暖色。参数（母版 `build_logo_svgs.py`）：画心 (256,200)、viewBox 512×460、R_OUT 100 / R_IN 71（笔画宽 29）、黑弧 0°→300°、金弧 305°→332°（45° 斜切端头）、G 杠 y=200 / x=239→356。

### 2.2 资产选择速查

| 场景 | 文件 |
|---|---|
| 白 / 浅灰纸面 | `caigong-fde-logo-master.svg` |
| 深色 UI / 大屏 | `caigong-fde-logo-inverse.svg` |
| 单色印刷 / 丝印 / 合同页眉 / 雕刻 | `caigong-fde-logo-mono-dark.svg` |
| 深底单色 / 烫白 | `caigong-fde-logo-mono-light.svg` |
| 头像 / 底纹 / 图标 / 水印 | `caigong-fde-mark.svg` / `-mark-inverse.svg` |
| 应用图标 / favicon | `caigong-fde-app-icon.svg` / `-favicon.svg` |

> ⚠️ `caigong-fde-logo-concepts.miora` 及 `_assets/` 内位图**带平台「AI生成」溯源标识，禁止用于任何正式对外物料**。

### 2.3 尺寸与留白

| 项 | 下限 |
|---|---|
| 完整组合（含字标） | 宽 ≥ 120px |
| 纯图形标 | ≥ 24px |
| favicon | 16px 起（金点仍可辨） |
| 图形四周留白 | ≥ 图形高度 1/4 |
| 组合四周留白 | ≥ 图形高度 1/2 |
| 图形与字标间距 | 图形高度 0.55 倍；字标总宽 ≥ 图形宽 1.0 倍 |

### 2.4 禁用项

不得拉伸变形、不得改变环形开口方向、不得移动金色段位置；不得加描边、投影、渐变；不得在标准字内部换色；不得重排字标顺序或删改任一字符；不得把主标裁切/变形后当功能图标；不得把主标当印章使用（D6）。

> 详见 `BRAND-LOGO-GUIDE.md §五/§六/§七`。

## 03 · 色彩系统

**完整规范见独立文档 `BRAND-COLOR-SPEC.md`**，本章只给使用要点：

1. 主色石墨黑 `#14181C`（80–85%）+ 辅色琥珀金 `#E8A33D`（10–15%）+ 中性灰，其余不引入第三种彩色。
2. 深底金色提亮 `#F5B44A`；UI 交互用金墨 `#C98F2B`、hover 深金 `#A3721F`。
3. 金色全场只出现一处；语义色（success/warning/danger）保持原色相，不参与品牌表达。
4. 单色印刷只用石墨黑或纯白，不保留金段色相。
5. 数据可视化色板**未发布**（保留「留待图表需求出现时补」注记），图表页不得自行造色。
6. ✅ **金系按钮 / 激活态 / 金底图标一律配石墨黑字 `#14181C`**（2026-11-06 裁决）：白字实测 2.16–2.82:1 不达 AA，已全面替换；石墨黑字主态 6.33–8.27:1 达标。⚠️ hover 深金 4.23:1 残留见 `BRAND-COLOR-SPEC.md §十-8`。

## 06 · 数字载体应用示例

| 载体 | 正确做法 | 常见错误 |
|---|---|---|
| 桌面端侧边栏 | 深底 + `mark-inverse` 反白图形标 | 浅底放反白标（白 G 隐形） |
| 登录页 | 图形标 + 产品名（取 `brand.ts`）+ slogan 全句，浅底用 `logo-caigong-fde-light.svg` 等价资产 | 用反白标放白底 |
| 官网 hero | 深底 `logo-inverse` + slogan + §〇 定稿介绍全句 | 改写介绍、漏主标、写「九步」 |
| 官网门禁轨道 | G1–G9 名称按 `gates.json`，文字+线条表达 | 自造门禁名、擅自加图表色 |
| 公众号头像 | `app-icon` 或 `mark` 方形版，深底反白 + 单金段 | 加文字/边框/概念稿位图 |
| 邮件签名 | `assets/email-signature.html`，全内联 CSS，字段 `[[待确认]]` | 填入虚构联系方式、用外链字体 |
| PPT | `deliverables/caigong-fde-ppt-template.pptx`，封面/内页/图表页/封底 | 图表页自行造色、封面漏 slogan |
| 产品截图 | 1440×900 建议尺寸、2x PNG、全脱敏、无控制台/调试面板 | 露出真实客户名、内网地址、半截卡片 |
