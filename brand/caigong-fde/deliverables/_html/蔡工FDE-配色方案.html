一、为什么要独立成文

本次核查结论：docs/ 全目录对「配色方案 / 品牌全案 / 品牌手册 / 品牌故事 / 话术口径」等词零命中；配色规范此前仅嵌在 BRAND-LOGO-GUIDE.md §三，没有独立文档；《品牌全案策划书》此前实为 BRAND-ASSET-CHECKLIST.md 清单。

这导致三个问题：色值散落在 LOGO 规范里、UI tokens 里、官网 HTML 里，没有一处可被引用的单一真源；配色调整时无法判断该改哪份文件；新增载体（图表、印刷、丝印）无规可依。

本文即为此缺口而建：把已落地的色值收拢为独立、可引用、可归档的配色方案；同时不新增任何未经确认的色值——未定事项一律写入 §十「待确认项」。

二、色彩定位与角色定义

主标为「石墨黑 C 形环 + 右上单一金段」。配色系统从这个图形直接推导：结构是黑的，强调是金的，其余全是中性灰。

主色 石墨黑 Graphite #14181C 80%–85% 结构与文字的锚，可靠、不喧哗
辅色 琥珀金 Amber #E8A33D 10%–15% 全场唯一暖色，对应主标右上那一小段金
辅色（深底提亮） 亮琥珀金 #F5B44A 深底专用 深色背景上保证金段可辨

方法：WCAG 2.x 相对亮度公式（sRGB 线性化，阈值 0.04045、γ 2.4），对比度 = (L₁ + 0.05) / (L₂ + 0.05)。本次以脚本对本文所有色值重新计算。

#1A2027 / #F6F6F4 15.16:1 ✅ ✅
#6B7280 / #FFFFFF 4.83:1 ✅ ✅

⚠️ 与既有文档的差异（如实记录，不掩盖）：BRAND-LOGO-GUIDE.md §三 与清单 B3 记的约数为「琥珀金约 2.2:1 / 金墨约 3.4:1 / 深金约 4.8:1，白字对比达标 WCAG AA」。按 WCAG 公式实测分别为 2.16 / 2.82 / 4.21，且金墨、深金配白字均未达到 AA 正文 4.5:1（深金达到大字 3:1）。约数偏乐观，本文以实测为准。

处置（2026-11-06 已裁决并落地）：用户裁决 A「金系按钮文字改石墨黑字」。已把 styles.css / pages.css / ai-server-chat.css / site/index.html 中全部 9 处金底白字规则改为 var(--brand-ink) / var(--ink)，BRAND-LOGO-GUIDE.md §三 的偏乐观约数同步改为实测值；品牌色值本身零改动，深底侧边栏白字保持不变。§三 与清单 B3 的旧约数已作废。

⚠️ 残留风险（不改色值，如实登记）：hover 深金 #A3721F 上石墨黑字仅 4.23:1（白字 4.21:1），仍略低于 AA 正文 4.5:1，但达大字/图标 3:1。若要彻底达标须调整 hover 色值或改换 hover 反馈，属于色值变更（破坏性变更），本次未擅自执行，列入 §十-8。

七、用色纪律（强制）

  1. 金色只出现在一个位置（主标右上分段），是全场唯一暖色；任何画面中不得出现第二处金色强调——UI 交互色除外，它本来就是金色系。
  2. 深色背景时金色必须提亮至 #F5B44A。
  3. 不得引入第三种彩色（蓝 / 绿 / 青 / 紫等）；所有非品牌色只能是石墨阶、中性灰、纯白。
  4. 语义色保持原色相，不参与品牌表达；也不得被改写为金色。
  5. 单色印刷/丝印/合同页眉只用石墨黑或纯白，不保留金段色相（靠 45° 斜切端头与缺口区分）。
  6. 不得给主标或母题加渐变、投影、描边效果；--brand-gradient 仅用于 UI 控件，不用于主标。

正误对照

✅ 正确 ❌ 错误
浅底 master + 一处金 浅底铺满金色块 / 多处金强调
深底 inverse + #F5B44A 深底仍用 #E8A33D（对比不足）
金系按钮/金底图标配石墨黑字（2026-11-06 起强制） 金系按钮配白字（2.16–2.82:1，已禁用）
图表状态用语义色 把 success/danger 改成金色
页面底色 #F6F6F4 + 石墨阶文字 引入蓝灰/青绿作「品牌感」点缀
单色稿用 mono-dark/mono-light 单色稿里硬留一小块金色
