## 〇、品牌话术（2026-11-04 定稿）

**Slogan：交付有据，一步到位**
- 「有据」= 门禁 G1–G9、证据链、可追溯——产品的灵魂
- 「一步到位」= 效率承诺——客户购买的理由
- 与 CG 环形标互补：标管可靠（闭环+验收刻痕），话管高效
- 英文短句（官网阶段定稿）：候选 "Evidence in every delivery."

**一段话品牌介绍（100 字内，全渠道统一，2026-11-05 按真实 SOP 口径修正；2026-11-06 行业口径裁决为「全行业企业」）**：
> 蔡工FDE智能交付系统，面向全行业企业的智能交付工作台。以 13 阶段交付 SOP 和 G1–G9 门禁把每一次实施变成可追溯、可验收的标准动作——从需求到验收，一个闭环，交付有据，一步到位。

> 本句以 `site/index.html`（`<meta name="description">` 与 hero 正文）为定稿真值；旧版「九步交付法」为事实错误，已按 `server/seeds/gates.json`（G1–G9 门禁定义）与 13 阶段交付 SOP 修正。所有新物料一律引用本句，不得回退。
> **行业口径 2026-11-06 裁决为「全行业企业」**（工作台实已扩展至全行业，原行业限定表述退役）：仅替换该短语，句式与其余文字逐字不变。

**使用规则**：slogan 独立出现时不加标点也可（交付有据 一步到位）；名片/封面用全句含逗号；介绍文字不得自行改写，改版须走品牌文档变更。

## 一、定稿决策与理由

| 维度 | 判断 |
|---|---|
| 字母锁定 | C + G 直接对应「蔡工」，个人信用是本品牌最难被复制的资产 |

**方案二/三/四/六 归档**，作为后续 VI 延展的备选元素库（尤其方案六的流动线条可用于吉祥物或动效延展）。

## 三、色彩规范（v1.1 完整色阶 2026-11-04；2026-11-06 文字色裁决修订）

| 角色 | 名称 | 色值 | 用量占比 |
|---|---|---|---|
| 主色 | 石墨黑 Graphite | `#14181C` | 80%–85% |
| 辅色 | 琥珀金 Amber | `#E8A33D` | 10%–15% |
| 辅色（深底提亮） | 亮琥珀金 | `#F5B44A` | 深底专用 |
| 交互主色 | 金墨（按钮/激活态） | `#C98F2B` | UI 交互 |
| 交互深端 | 深金（hover） | `#A3721F` | UI hover |
| 中性面 | 浅中性 | `#F2F4F5`（印刷）/ `#F6F6F4`（桌面端 bg） | 背景 |
| 深底面 | 深炭 | `#1A1F24` / `#14181C` | 深色背景 |
| 反白 | 纯白 | `#FFFFFF` | 深底文字与图形 |

**色阶（与桌面端 `styles.css :root` 同源）**

| 金色阶 | 值 | 石墨阶 | 值 |
|---|---|---|---|
| gold-1 | `#FBEECC` | ink-1 | `#14181C` |
| gold-2 | `#F5B44A` | ink-2 | `#23282E` |
| gold-3 | `#E8A33D` | ink-3 | `#3A4048` |
| gold-4 | `#C98F2B` | ink-4 | `#5A626D` |
| gold-5 | `#A3721F` | ink-5 | `#8A929E` |

**交互色与按钮文字色（2026-11-06 裁决落地）**：白字在琥珀金 `#E8A33D` / 金墨 `#C98F2B` / 深金 `#A3721F` 上的 WCAG 实测对比度为 **2.16 / 2.82 / 4.21:1**，均不达 AA 正文 4.5:1；早期约数 2.2 / 3.4 / 4.8 偏乐观，**已作废**。裁决：**所有金系按钮、激活态与金底图标上的文字/图形统一改用石墨黑 `#14181C`**，实测 8.27 / 6.33 / 4.23:1；**品牌色值不变、hover 深端不变**。按钮/激活态仍用「金墨 → 琥珀金」渐变。⚠️ hover 深金上的石墨黑字为 4.23:1，仍略低于 AA 正文（大字/图标达标），属**已知残留风险**，未擅自改色值，见 `BRAND-COLOR-SPEC.md §六/§十-8`。

**用色纪律**
- 金色只出现在**一个**位置（右上分段），是全场唯一暖色，任何画面中不得出现第二处金色强调（UI 交互色除外——它本来就是金色系）。
- 深色背景时金色必须提亮至 `#F5B44A`，否则对比不足。
- 不得引入第三种彩色。
- **金系按钮/激活态/金底图标一律配石墨黑字 `#14181C`，不得配白字**（2026-11-06 裁决；实测见 §三 与 `BRAND-COLOR-SPEC.md §六`）。
- 语义色（success/warning/danger）保持各自色相，不做品牌化改写——功能性颜色不参与品牌表达。

## 六、使用规范

**最小尺寸**
- 完整组合（含字标）：最小 **120px** 宽
- 纯图形标：最小 **24px**
- favicon：16px 起（此时仅图形，金点仍可辨）

**留白**
- 图形四周留白 ≥ 图形高度的 1/4
- 组合四周留白 ≥ 图形高度的 1/2

**禁止**
- 不得拉伸变形、不得改变环形开口方向、不得移动金色段位置
- 不得给图形加描边、投影、渐变、描边以外的效果
- 不得在标准字内部换色
- 不得重新排列字标顺序或删改任一字符

**正确用法**
- 浅底 → `logo-master`；深底 → `logo-inverse`
- 单色印刷/丝印 → `mono-dark` 或 `mono-light`
- 头像/水印/应用图标 → `mark` / `app-icon` / `favicon`
