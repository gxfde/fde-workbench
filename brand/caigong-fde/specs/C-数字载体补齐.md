| **待确认项** | ① 姓名、职位、电话、邮箱、公司主体全称、官网域名——**全部待确认，模板中以 `[[...]]` 占位，不含任何虚构值**；② 图片托管地址（内联 data-URI 还是外链）——待确认；③ 是否加免责声明/保密声明及其法务措辞——**待确认，须法务确认**；④ 移动端签名折行规则；⑤ 是否需要英文签名版；⑥ 全员分发与更新责任人（联动 F2/F3） |

### 核心内容

**C7-1 模板结构（`assets/email-signature.html`）**

| 区块 | 内容 | 规范 |
|---|---|---|
| 左列 | 纯图形标小图标 | 宽 56px，透明底或白底，用 `mark` 不上字标 |
| 右列 · 第 1 行 | 姓名（加粗）+ 职位 | 中文思源黑体 Bold / 12–14px（建议值 · 待确认） |
| 右列 · 第 2 行 | 品牌名「蔡工FDE智能交付系统」 | 逐字引用 A1 全称，不加粗变形 |
| 右列 · 第 3 行 | 电话 ｜ 邮箱 ｜ 官网 | 数字与编号用 B4 等宽数字；全部 `[[占位]]` |
| 分隔 | 1px 金段线（`--brand-gold` / `#E8A33D`） | 全长不超过 320px，全场唯一金色 |
| 底行 | slogan「交付有据，一步到位」 | §〇 原句，不作变体 |

**C7-2 技术约束**

- 单文件 HTML，`table` 布局 + **全内联 CSS**（邮件客户端不保证 `<style>` 生效），宽度 ≤ 600px。
- 图片优先内联 data-URI 避免被拦截；若用外链，地址**待确认②**，且必须是可公开访问的 HTTPS 地址。
- 不使用 web font（邮件客户端不支持），回退字体栈须包含中文黑体。
- 不放二维码、不放追踪像素、不放社交图标（未立项）。
- 所有文字可选中可复制，不把关键信息做进图片。

**C7-3 分发**：模板更新后由 F2 记录版本，F3 季度巡检抽查全员签名是否为最新版。

## C9 ｜ 产品截图规范

| 字段 | 内容 |
|---|---|
| **名称** | 蔡工FDE智能交付系统 — 产品截图与脱敏规范 |
| **适用范围** | 官网、案例、提案、公众号、品牌手册、帮助文档、桌面端引导页中的产品界面截图 |
| **与现有文件的引用关系** | 主题色 = `desktop/src/renderer/src/styles.css :root`（浅色为默认）；术语 = A5；摄影/插图 = B7；图标 = B6；下游 = C6 推文、C8 提案、《品牌手册（完整版）》应用示例页 |
| **待确认项** | ① 标准窗口尺寸（本文给建议值，须按实际界面复核）；② 是否允许出现真实客户/项目名及其审批人——**待确认，未确认前一律脱敏**；③ 深色主题是否作为对照版纳入；④ 截图是否需带浏览器/系统外框；⑤ 归档目录与命名责任人（联动 F2） |

### 核心内容

**C9-1 采集基线（建议值 · 待确认①）**

| 项 | 建议值 |
|---|---|
| 窗口尺寸 | 1440 × 900（桌面端）；官网截图 1440 × 首屏高度；移动端 390 × 844 |
| 缩放 | 100%，导出 2x PNG；禁用系统缩放与浏览器缩放 |
| 主题 | 默认浅色主题（`--bg #F6F6F4` / `--surface #FFFFFF`）；深色版需单独标注 |
| 状态 | 使用**演示数据**，界面数据完整但不得为空表/报错态；不显示加载动画中间帧 |
| 界面洁净 | 隐藏开发者工具、控制台、调试面板、通知气泡；光标不留在画面内 |
| 滚动位置 | 顶部对齐，不截取半截卡片/半截表格行 |

**C9-2 脱敏规则（强制）**

| 类别 | 处理 |
|---|---|
| 客户/项目名 | 替换为「示例客户」「示例项目」（待确认②，未批准不得出现真实名称） |
| 人名 / 手机号 / 邮箱 | 替换为占位；不得只打码部分字符 |
| 金额 / 报价 / 合同编号 | 替换为示意值，且需注明「示意」 |
| 门禁记录中的真实证据 | 不出现在对外截图 |
| 屏幕内可见的 URL / 内网地址 / 端口 | 一律裁掉或遮盖 |
| 时间戳 | 统一为示意日期 |

**C9-3 输出与归档**

- 格式 PNG（无损）、2x；文件命名 `caigong-fde-shot-<场景>-<主题>-v<版本>.png`（遵循 F2 命名法）。
- 每张截图附一行说明：场景、主题、脱敏状态、采集日期；说明存于同目录 `README`。
- 禁止把截图二次压缩成 JPEG 后用于印刷物料。
- 主标在截图中须符合 §六 最小尺寸与留白；不符者重截，不得后补放大。
