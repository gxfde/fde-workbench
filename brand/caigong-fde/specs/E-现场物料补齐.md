## E1 ｜ 工作服 / 安全帽丝印稿

| 字段 | 内容 |
|---|---|
| **名称** | 蔡工FDE智能交付系统 — 工装与安全帽单色丝印工艺规范 |
| **适用范围** | 驻场工作服（左胸 / 后背）、安全帽正面、马甲；不用于反光条、安全标识（客户方制式为准） |
| **与现有文件的引用关系** | 单色源资产 = `caigong-fde-logo-mono-dark.svg`（浅色衣）/ `-mono-light.svg`（深色衣）；几何母版 = `build_logo_svgs.py`（R_OUT 100 / R_IN 71、笔画宽 29）；色值 = `BRAND-COLOR-SPEC.md`（单色印刷仅石墨黑或纯白）；辅助图形 = B5；清单 E1 原要求「矢量轮廓化 + 最小线宽 ≥2mm + 安全区 + 深浅两版」 |
| **待确认项** | ① 衣色的实际 Pantone / 供应商色卡——**待确认，深浅两版的分界需据此判定**；② 供应商最小线宽复核（2mm 为清单给定下限，须按实际网目/刺绣工艺确认）；③ 印刷工艺（丝印 / 热转印 / 刺绣 / 激光雕刻）选定；④ 是否为安全帽曲面另做变形补偿；⑤ 是否需反光/耐洗/阻燃材质认证；⑥ 客户现场是否强制佩戴其自有标识或色带 |

### 核心内容

**E1-1 工艺硬性要求**

| 项 | 要求 |
|---|---|
| 图形处理 | **矢量轮廓化**：把描边全部 `outline stroke`，避免不同 RIP 解释线宽；轮廓化后不改变环形开口方向与金段角度 |
| 最小线宽 | ≥ 2 mm（清单 E1 下限）；按母版笔画宽 29 等比换算后须 ≥ 该值，否则放大图形而非减细笔画 |
| 单色 | 只用一个色版；**金色不出片**（丝印单色稿不保留金段色相，金段与黑弧同为单色、靠 45° 斜切端头与缺口区分） |
| 深浅两版 | 浅衣 → `mono-dark`（石墨黑 `#14181C`）；深衣 → `mono-light`（纯白 `#FFFFFF`） |
| 安全区 | 图形四周 ≥ 图形高度 1/4（§六）；距缝线/口袋/帽檐 ≥ 10mm（建议值 · 待确认③） |
| 禁止 | 不加描边、投影、渐变；不拉伸变形；不与文字重排；不使用带平台标识的概念稿位图 |

**E1-2 建议落位（建议值 · 待确认③④）**

| 位置 | 建议图形宽 | 说明 |
|---|---|---|
| 工作服左胸 | 80 mm | 纯图形标优先；如需品牌名，用完整组合且宽 ≥120px 等效 |
| 工作服后背 | 200 mm | 单色，居中；不得加 slogan 大字 |
| 安全帽正面 | 60 mm | 曲面需变形补偿，待确认④ |
| 马甲左胸 | 80 mm | 同工作服 |

**E1-3 交付流程**：`mono-dark/mono-light` SVG → 轮廓化 → 按衣色选版 → 供应商打样 → 目检金段缺口在单色下仍可辨 → 出片。打样未通过不得批量制作。
