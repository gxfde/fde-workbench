## B3 ｜ 数据可视化色板（条件待补）

| 字段 | 内容 |
|---|---|
| **名称** | 蔡工FDE智能交付系统 — 数据可视化色板（预留规范，未发布色值） |
| **适用范围** | 未来的报表、报价单、G1–G9 门禁轨道图、仪表盘、PPT 图表页、官网数据图；**当前不生效**，不用于任何现有物料 |
| **与现有文件的引用关系** | 依附 `BRAND-COLOR-SPEC.md §三/§六`（品牌色阶与「不得引入第三种彩色」纪律）；依附 `BRAND-ASSET-CHECKLIST.md` B3 原注记；影响 C8 图表页模板、C9 截图规范、`site/index.html` 门禁轨道图（现有轨道图为文字+线条，未使用数据色板） |
| **待确认项** | ① **图表需求是否出现**（触发条件，见下）；② 序列数量上限、是否需区分维度／状态／对比组；③ 色觉无障碍（CVD）验收标准；④ 是否允许在图表内引入品牌色之外的中性灰阶；⑤ 图表色板一旦发布，与语义色 success/warning/danger 的优先级关系；⑥ 审批人与发布版本 |

### 核心内容

> **⚠️ 保留原注记（逐字）**：**「数据可视化色板留待图表需求出现时补」**
>
> 本规范因此**不给出、不指定、不示意任何具体图表色值**，也不以品牌色阶临时拼凑一套序列色充数。以下只定义触发条件、推导原则与验收流程，供需求出现时按流程补齐。

**B3-1 触发条件（满足任一即启动补色）**

1. 出现需要区分 ≥2 个数据 series 的图表（折线/柱状/堆叠/饼图）。
2. 出现需要用颜色编码状态的图表（进度、门禁通过率、风险等级）。
3. C8 PPT 模板的图表页、或官网/提案中出现真实数据图需求。

**B3-2 补色时必须遵守的既有纪律（引用，不新增色值）**

- 主色石墨黑、辅色琥珀金的角色与用量占比不变（见 `BRAND-COLOR-SPEC.md §二`）。
- 「不得引入第三种彩色」为品牌级纪律；数据图表若确需多色区分，须**先由品牌责任人裁决是否豁免**，并在本规范中书面记录豁免范围，不得默认放行。
- 语义色（success/warning/danger）保持各自色相，不参与品牌表达，也**不得**被借用作数据序列色。
- 深色背景下金色提亮至 `#F5B44A`，规则同 `BRAND-COLOR-SPEC.md §四`。
- 优先级建议（**待确认⑤**）：语义色 > 数据序列色；即图表表达「通过/不通过」时用语义色，不占用序列色。

**B3-3 补色流程（待触发时执行）**

```
需求出现 → 明确 series 数量/状态维度/输出介质（屏/印刷/投影）
        → 提出色板候选（须含 hex + 对比度 + CVD 模拟结果）
        → 与 BRAND-COLOR-SPEC.md 交叉检查「第三种彩色」纪律
        → 品牌责任人书面拍板（含是否豁免） → 写入本文件并升版
        → 同步 C8 图表页模板 / C9 截图规范 / F2 CHANGELOG / F3 巡检
```

**B3-4 当前状态**：**条件待补（未发布）**。现有 `site/index.html` 的 G1–G9 门禁轨道图使用文字与线条表达，不依赖数据色板，因此不受本节阻塞。

### 核心内容

**B5-1 三个母题（均从主标几何直接推导，不引入新图形语言）**

| 母题 | 几何来源 | 用法 | 交付文件 |
|---|---|---|---|
| ① 金段弧线 | 金弧 305–332°、45° 斜切端头，笔画宽 29（按母版比例） | 短分割线、标题下的强调线、页眉金线；**只出现一处** | `assets/aux-gold-arc.svg` |
| ② 进度刻度环 | 黑弧 0–300° 九等分刻度，末端对应金弧 305–332° | G1–G9 进度示意、加载环、章节序号环 | `assets/aux-progress-ring.svg` |
| ③ 闭环箭头 | 环形回环笔势，收口落在右上金段起点 | 「闭环/交付完成」语义配图、流程图收尾 | `assets/aux-loop-arrow.svg` |

> 三个 SVG 为**可直接使用的延展草案**，均由母版参数生成，无平台水印、无新增彩色；正式对外前须经①拍板。

**B5-2 使用纪律**

1. 母题是**背景级/装饰级**元素：同一画面中视觉权重必须低于主标，不得与主标争夺视线。
2. 金色仍遵守「全场唯一暖色」纪律：母题中的金段与主标金段同时出现时，**只保留一处金色**，另一处降为石墨阶（ink-4/ink-5）或白色。
3. 不得改变环形开口方向、不得把金段移到其他角度、不得给母题加投影/渐变/描边（同 §六 禁用项精神）。
4. 底纹使用时不得压在正文下方影响可读性；上限值**待确认②**。
5. 单色印刷/丝印场景一律用 `mono-dark` / `mono-light` 的等效单色处理，母题不得单独带金。

**B5-3 正误对照（摘录）**

| ✅ 正确 | ❌ 错误 |
|---|---|
| 标题下一条 45° 斜切金段线，其余装饰用石墨阶 | 满版金色弧线重复铺陈 |
| 进度环与主标分置版面两侧 | 把进度环当作 logo 放在页眉品牌位 |
| 深色底用白色母题 + 单点提亮金 | 深色底仍用 `#E8A33D` 金段（对比不足） |

## B6 ｜ UI 图标风格规范

| 字段 | 内容 |
|---|---|
| **名称** | 蔡工FDE智能交付系统 — UI 图标风格规范 |
| **适用范围** | 桌面端功能图标、官网图标、PPT/提案图示、空状态图标；不含主标、app icon、favicon（这些由 B1 单独管理） |
| **与现有文件的引用关系** | 网格/线宽建议对应清单 B6 原描述「1.5px 线性+圆角、24px 网格」；色值 = `BRAND-COLOR-SPEC.md` 与 `styles.css :root`（语义色、文字色、描边色）；与 B7 插图、B5 母题共用几何语言；下游 = C9 截图规范（截图内不得出现不符合本规范的图标） |
| **待确认项** | ① **桌面端现有图标库盘点结果**——未盘点，本规范暂不宣布「与现有图标统一」已达成；② 现有图标是线性还是面性、来源库与授权——**待确认**；③ 圆角值最终取值；④ 是否引入品牌自有图标集，或延续第三方库；⑤ 暗色主题下的线宽补偿规则 |

### 核心内容

**B6-1 建议基线（建议值 · 待确认①③④）**

| 项 | 建议值 | 说明 |
|---|---|---|
| 设计网格 | 24 × 24 px | 内容安全区 20 × 20，四周留 2px |
| 风格 | 线性优先，圆角端点/连接 | 与环形主标的连续笔势一致 |
| 描边 | 1.5px（@1x），按 2x/3x 等比导出 | 不得出现 1px 以下的细线 |
| 端点 | `stroke-linecap: round`；`stroke-linejoin: round` | 呼应主标圆润收笔 |
| 圆角 | 2px（外框）/ 1px（内角） | 建议值 · 待确认③ |
| 光学对齐 | 视觉重心居中，不按 bounding box 机械居中 | 圆形图标可略外扩 |
| 尺寸档 | 16 / 20 / 24 / 32 px | 16px 时允许简化细节，不得直接缩放 24px 稿 |

**B6-2 用色**

- 默认图标色取 `styles.css` 文字/描边阶（不硬编码新 hex）；激活态用交互主色金墨 `#C98F2B`，**金底图标的字形/图形一律用石墨黑 `#14181C`，不得用白**（2026-11-06 裁决，见 `BRAND-COLOR-SPEC.md §六`）。
- **图标不得用金色填充**：金色是主标专属强调位；图标只允许在激活/选中态使用金系。
- 状态类图标使用语义色（success / warning / danger），语义色不参与品牌化改写。
- 单色场景（打印、丝印、合同页眉）统一石墨黑或反白，不保留多色。

**B6-3 禁止**

- 不得给图标加投影、渐变、3D、拟物质感。
- 不得把主标 CG 环形裁切/变形后当功能图标用。
- 不得把不同来源、不同线宽的图标混排在同一组控件内。
- 不得用颜色单独承载含义（须配文字或形状），以满足可访问性。

**B6-4 落地前置**：完成待确认①的图标库盘点后，须把本表「建议值」与现状差异列成整改清单，再宣布 B6 完成；**当前状态 = 规范已出，统一待核**。

### 核心内容

**B7-1 双轨定义**

| 轨道 | 风格 | 适用 |
|---|---|---|
| 轨道 A · 现场摄影 | 只拍真实交付现场（设备、工装、文档、手部动作）；低饱和、以石墨中性灰为基调；暖色只允许来自现场光源或金属反光，**不得后期注入第二种彩色**；避免人物正脸（授权未明确前） | 官网 About、展会、案例、品牌故事配图 |
| 轨道 B · 几何矢量插图 | 与主标同语言：圆弧、刻度、直线、45° 斜切；线宽按 B6 的 1.5px 体系；只用石墨阶 + 单点金；不加渐变、不加拟物阴影 | 空状态、功能说明、PPT 示意、公众号头图 |

**B7-2 色调处理（引用既有色值，不新增颜色）**

- 基调：`#14181C` / `#F6F6F4` / 石墨阶 ink-1…ink-5。
- 唯一暖色：`#E8A33D`（浅底）/ `#F5B44A`（深底）；一张图内金色面积不超过画面 10–15%，且只落在一处。
- 语义色不进入摄影/插图调色；不得用滤镜把画面染成蓝、绿、青等第三色相。
- 黑白/单色印刷场景直接去色，不单独出一套彩色版。

**B7-3 禁用**

- 禁止使用图库风格的商务握手、地球、齿轮堆叠等泛化素材。

| 字段 | 内容 |

| **与现有文件的引用关系** | 语义来源 = `BRAND-LOGO-GUIDE.md §〇`（「一步到位」= 推进感）与 §二（金段 305–332°）、§六（不得移动金色段位置/不得改开口方向）；色值 = `BRAND-COLOR-SPEC.md`；母题 = B5 进度刻度环；现状 = `site/index.html`（当前无动效，待确认是否引入） |

### 核心内容

**B8-1 核心母题：金段递进**

金弧 305°→332° 是全标唯一暖色，也是「交付推进」的天然载体。动效只允许表现为**这段弧随进度展开**，不得表现为整环旋转、闪烁或颜色跳变。

| 状态 | 表现 | 参数（建议值 · 待确认①） |
|---|---|---|
| 加载中 | 金段从 305° 起点沿弧长生长至 332°，到端点后回到起点循环 | 单周期 1200ms，`linear` |
| 进度反馈 | 金段展开比例 = 已完成门禁数 / 9（G1–G9），不循环 | 240ms，`cubic-bezier(0.2, 0, 0, 1)` |
| 成功 / G9 达成 | 金段一次展开到满，随后停住不回落 | 320ms，`cubic-bezier(0.2, 0, 0, 1)` |
| 失败 / 未通过 | **不做失败动画**，保持静态并由语义色 + 文字表达（语义色不参与品牌表达） | — |
| UI 微交互 | 按钮 hover / 激活态沿用 `styles.css` 现有过渡，不新增品牌动画 | 沿用现有实现 |

**B8-2 主标动效版原则（视频/PPT 片头）**

1. 环形黑弧先以单笔连续路径绘出（0°→300°），方向固定，不得反向。
2. 金段最后出现（305°→332°），出现即停，不闪、不脉冲。
3. G 横杠随黑弧收笔一次性落位。
4. 全过程中**不得改变开口方向、不得移动金段角度、不得加投影/发光/渐变**——与 §六 禁用项一致。
5. 出现字标时，字标静态淡入，不做逐字弹跳。

**B8-3 可访问性与性能**

- 必须响应 `prefers-reduced-motion: reduce`：降级为静态满幅金段，不播放任何循环动画。
- 循环动画仅用于「加载中」，加载结束立即停止；禁止常驻无限动画。
- 不得为动效新增彩色、新增音效或自动播放视频（待确认④）。

**B8-4 当前状态**：规范已出；**未产出动效成品、未改任何线上代码**。待确认②③落定后再实施，避免改动现有稳定功能。
